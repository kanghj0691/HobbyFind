# HobbyFind 유스케이스 문서 (Use Case Specification)

---

# 1. 액터 정의 (Actor Definitions)

| 액터              | 설명                         | 권한                 |
| --------------- | -------------------------- | ------------------ |
| 비회원 사용자 (Guest) | 로그인하지 않은 사용자               | 홈/카테고리 탐색만 가능      |
| 회원 사용자 (Member) | 로그인한 사용자                   | 탐색, 북마크, 마이페이지 이용  |
| 시스템 (System)    | 인증, 데이터 조회 및 저장을 수행하는 웹서비스 | 사용자 요청 처리 및 데이터 관리 |

# 2. 상세 Use Case 시나리오 (Detailed Use Case Scenarios)

## UC-01. 메인페이지 탐색

### 개요

사용자가 홈페이지에서 취미 목록을 탐색한다.

| 항목          | 내용              |
| ----------- | --------------- |
| Use Case ID | UC-01           |
| Use Case    | 메인페이지 탐색        |
| 액터          | 비회원, 회원         |
| 목적          | 전체 취미 목록을 확인한다. |

### 기본 흐름

| 단계 | 액터              | 시스템                     |
| -- | --------------- | ----------------------- |
| 1  | 홈페이지 접속         | 홈 화면을 표시한다.             |
| 2  | 사용자가 페이지를 탐색한다. | Hero 및 취미 카드 목록을 표시한다.  |
| 3  | 취미 목록을 확인한다.    | 전체 취미 카드를 그리드 형태로 제공한다. |

### 결과

* 사용자는 전체 취미를 확인할 수 있다.

| 항목          | 내용      |

## 전체 흐름

```text
사용자 접속
      │
      ▼
홈페이지 조회
      │

      │         │
      │         ▼
      │   카테고리 페이지
      │
      ├── 로그인
      │         │
      │         ▼
      │   회원 상태

      │
      └── 마이페이지 조회
```

# 4. 대체 흐름 및 엣지 케이스 (Alternative Flows and Edge Cases)

| 상황                       | 시스템 동작                  |
| ------------------------ | ----------------------- |
| 로그인하지 않은 사용자가 북마크 클릭     | 로그인 페이지로 이동             |

| 통계 데이터 없음                | 빈 차트 또는 0건으로 표시         |
| 존재하지 않는 카테고리 URL 접근      | 404 페이지 표시              |

# 6. 비즈니스 규칙 및 제약사항 (Business Rules and Constraints)

* 악기 연주
* 요리
* 서예
* 도자기 만들기
* 정원 가꾸기

# 10. 보안 및 개인정보 고려사항 (Security and Privacy Considerations)

| 항목       | 고려사항                                               |
| -------- | -------------------------------------------------- |
| 비밀번호 저장  | 평문 저장 금지, 안전한 해시 알고리즘으로 암호화하여 저장                   |
| 로그인 인증   | 로그인 성공 시 사용자 세션을 생성하고 인증 상태를 유지                    |
| 접근 제어    | `/mypage`는 로그인한 사용자만 접근 가능                         |
| 북마크 권한   | 자신의 계정에 대한 북마크만 조회·추가·삭제 가능                        |
| 입력값 검증   | 로그인 및 회원가입 입력값을 서버와 클라이언트에서 검증                     |
| 세션 종료    | 로그아웃 시 인증 정보를 즉시 삭제하여 세션을 종료                       |
| 개인정보 최소화 | 회원가입 시 아이디와 비밀번호만 수집하며, 서비스 제공 목적 외의 개인정보는 수집하지 않음 |
