# PRD (Product Requirements Document)

## HobbyFind — 취미 탐색 및 북마크 웹서비스

---

# 1. 제품 상세 설명 (Detailed Product Description)

## 1.1 서비스 개요

| 항목     | 내용                                  |
| ------ | ----------------------------------- |
| 서비스명   | HobbyFind                           |
| 서비스 유형 | 웹 서비스                               |
| 대상 사용자 | 새로운 취미를 찾고 싶은 일반 사용자                |
| 회원 정책  | 비회원: 탐색만 가능 / 회원: 북마크 및 마이페이지 이용 가능 |

### 서비스 소개

HobbyFind는 사용자가 자신의 관심사에 맞는 취미를 쉽고 직관적으로 탐색할 수 있도록 제공하는 웹서비스이다.

취미는 다음 3개의 대분류로 구성된다.

* 운동형
* 지능형
* 예술형

사용자는 홈페이지 또는 카테고리 페이지에서 취미를 탐색할 수 있으며, 로그인한 회원은 원하는 취미를 북마크하여 마이페이지에서 관리할 수 있다.

# 2. 참고 서비스 및 근거 (Reference Services with Detailed Rationale)

| 참고 서비스    | 참고 요소       | 적용 이유              |
| --------- | ----------- | ------------------ |
| Pinterest | 카드(Grid) UI | 취미를 시각적으로 탐색하기 쉬움  |
| Goodreads | 관심 항목 저장    | 북마크 기능 UX 참고       |
| IMDb      | 카테고리 탐색     | 분류 기반 콘텐츠 탐색 구조 참고 |

### 선정 근거

* 카드 기반 UI는 콘텐츠 탐색 효율이 높다.
* 카테고리 필터는 사용자가 원하는 취미를 빠르게 찾도록 돕는다.
* 북마크 기반 개인화는 회원가입의 동기를 제공한다.
* 통계 차트는 사용자의 관심 분야를 직관적으로 확인하게 한다.

# 5. 기술 스택 추천 (Technical Stack Recommendations)

| 영역        | 기술                         |
| --------- | -------------------------- |
| Framework | Next.js                    |
| Language  | TypeScript                 |
| UI        | React                      |
| Styling   | Tailwind CSS               |
| 상태관리      | React Context API          |
| 차트        | Chart.js 또는 Recharts       |
| 인증        | NextAuth 또는 자체 아이디/비밀번호 인증 |
| 데이터 저장    | JSON 또는 SQLite (실습 환경 기준)  |
| 배포        | Vercel                     |

### 추천 이유

* **Next.js**: 파일 기반 라우팅과 서버 렌더링 지원으로 구조적인 웹 개발에 적합하다.
* **TypeScript**: 정적 타입을 통해 유지보수성과 안정성을 높인다.
* **Tailwind CSS**: 빠른 UI 구현과 일관된 스타일 관리가 가능하다.
* **React Context API**: 북마크 및 로그인 상태를 간단하게 관리하기에 적합하다.
* **Chart.js/Recharts**: 카테고리별 북마크 통계를 손쉽게 시각화할 수 있다.
* **SQLite 또는 JSON**: 실습 프로젝트에서 간단한 데이터 저장에 적합하다.
* **Vercel**: Next.js와의 연동이 뛰어나 손쉬운 배포가 가능하다.

# 6. 제한사항 (Limitations)

| 항목     | 내용                                   |
| ------ | ------------------------------------ |
| 취미 목록  | 제공된 18개의 취미만 사용하며 변경·추가·삭제하지 않는다.    |
| 카테고리   | 운동형, 지능형, 예술형의 3개 카테고리만 제공한다.        |
| 회원 기능  | 로그인, 회원가입, 북마크, 마이페이지만 제공한다.         |
| 비회원 기능 | 홈 및 카테고리 탐색만 가능하다.                   |
| 로그인 방식 | 아이디·비밀번호 기반 인증만 지원한다.                |
| 데이터 범위 | 프로젝트 실습용 데이터만 사용하며 외부 API와 연동하지 않는다. |
| 서비스 범위 | 요구사항에 명시된 페이지와 기능만 구현한다.             |
